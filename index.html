About the game

You begin deep in the forest, at night.

The Game of Hope is an interactive story set in a mythical, magical world. You make choices, meet characters, and journey through the landscape until you reach a clearing at dawn. That journey is a metaphor for how you will feel by the end.

It was built on the belief that technology can support wellbeing without being invasive. No data is stored. No account needed. Just you and the forest.

How to play

1
Clone the repo Download the project to your machine
2
Install dependencies Requires Python and HuggingFace Transformers
3
Run the game The story begins in your terminal
# clone
git clone https://github.com/shaniomallo/game-of-hope.git
cd game-of-hope

# install
pip install transformers torch

# play
python run_chatbot.py
